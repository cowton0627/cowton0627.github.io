# 讀書會 2023 - 1 後設戲劇
## 後設
- in Greek **-meta**
- in Lartin **-post** / **-ad**
- 雖然翻譯有個「後」，但卻不是在其後的意思，通常是在其上，及有「超越」之意。
- Metadata，是元數據、詮釋資料、後設資料
    - 內涵是資料的資料
    - 實際例子，圖片檔的 metadata
        - color space: RGB
        - alpha channel: none
        - dimension (resolution): 1920 x 1080
    - 照片檔的 metadata
        - 鏡頭大小: 24 mm、35 mm、70 mm
        - ISO: 800、1600、3200
        - 光圈大小: 0.7、1.4、2.8
        - 快門速度 | 快門開角: 1/60 | 180度
- Metaphysics
    - 形上學，先驗哲學，亞里斯多德
    - Physics，物理學
> 形而下者謂之器，形而上者謂之道。 -《周易》

所以形上學講的是不能直接透過感知得到答案，有一個先於感知的東西存在，什麼東西？例如基礎數學的公理，為什麼要證明 1 + 1 = 2，用到了皮亞諾公設。

又例如邏輯，平常人們講的你有你的邏輯 或 邏輯也是人定義出來的，這句話有根本上的錯誤。

副理說：「他」今天都沒有跟我講要請假, 他平常不會這樣 => 這個人沒請假就沒來上班 （正確與否?）

我請特休那天，我沒來上班 (合理嗎? 合理)
我沒來上班，又沒有曠職 => 循正規管道請了假 (正確與否?)

所以邏輯(希臘語 Logos，翻譯為 reason、discourse、language)是一種演繹法，並不是人定義出來的，可說是本來就存在的東西給予它名詞。

## Metadrama
- 打破第四道牆
    - 傳統舞台可以看成三面牆，演員面對觀眾席的背面，及此時的左右兩面。
    - 電影：《口白人生》、《楚門的世界》

- 戲劇
    - 保持疏離感，布萊希特（ AR ）；沈浸式 ( VR ) 
    - 方法演技
    - 互文性、共時性

- 例子
    - 過氣曾有才氣的舞台劇導演、因年齡漸長要轉換定位的女主角、帶稚氣卻充滿表演能量的新進男演員
    - 文本、影像、生活
    - 作者預示
