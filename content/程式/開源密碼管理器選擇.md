# 開源密碼管理器選擇

> 想從商業密碼管理器（1Password 這類）換到開源方案，主要考量是：
> 要能存**附件**（憑證檔、金鑰檔），要能跨 Mac / iPhone / Android / Windows 同步，
> 而且盡量免費。三個候選各自的取捨差很多。

---

## 三條路的對照

| 方案                    | 開源程度                         | 免費程度                                                      | 特點                                    |
| ----------------------- | -------------------------------- | ------------------------------------------------------------- | --------------------------------------- |
| **Bitwarden**（官方雲） | 客戶端 + 伺服器都開源            | 免費版筆數無限、全平台同步；**但附件要 Premium（約 $10/年）** | 最省事，體驗最接近商業方案              |
| **Vaultwarden**（自架） | Rust 重寫的 Bitwarden 相容伺服器 | **完全免費，含附件在內的進階功能全開**                        | 架在自己機器上，用官方 Bitwarden App 連 |
| **KeePassXC**           | 完全開源                         | 完全免費，附件原生支援                                        | 沒有伺服器，就是一個加密檔案，同步自理  |

---

## Vaultwarden：如果你本來就有一台機器

**它是什麼**：用 Rust 重新實作的 Bitwarden 伺服器端，API 相容。所以你可以用**官方的 Bitwarden App**（Mac / iOS / Android / 瀏覽器擴充）登入自己架的伺服器。

**為什麼吸引人**：官方雲要付費才有的功能（附件、TOTP、共享），自架版全部免費。

**資源需求極低**：一個 LXC 容器、記憶體 100MB 以內就跑得動。

**安全上的關鍵配置**：搭配 VPN，讓只有你 VPN 網路裡的裝置連得到，**完全不暴露公網**。密碼庫是最不應該掛在公開網路上的東西。

> [!warning] 自架的代價是備份責任
> 密碼庫機器掛掉、又沒有備份 = **所有密碼陪葬**。
> 自架密碼管理器**必須**配自動備份：資料庫檔定期複製到另一台機器。這不是「有空再做」的項目，是開始用之前就要做好的前置條件。

適合：已經有 homelab、願意把它當一個正式服務養的人。

---

## KeePassXC：最簡單粗暴

**它是什麼**：沒有伺服器，整個密碼庫就是**一個加密檔案**（`.kdbx`）。

**好處**：沒有伺服器就沒有伺服器故障點。備份就是複製檔案，簡單到不可能做錯。

**客戶端生態**（各平台都有成熟的第三方 App）：

| 平台                  | App                   |
| --------------------- | --------------------- |
| Mac / Windows / Linux | KeePassXC             |
| iOS                   | KeePassium、Strongbox |
| Android               | KeePass2Android       |

**同步自理**：走 iCloud Drive、Syncthing、或任何你信任的檔案同步。

**代價**：多裝置同時編輯可能衝突；自動填入的體驗不如前兩者流暢。

適合：筆數不多、主要存少數高價值機密、希望**維護成本趨近於零**的人。

---

## Bitwarden 官方免費版：最不用動腦

如果你不需要存附件，官方免費版其實就夠了——筆數無限、全平台同步、零維護。

會被淘汰通常只有一個原因：**要存附件**（憑證檔、金鑰檔、`.pfx` 之類），而附件卡在 Premium。

---

## 怎麼選

- 想當 homelab 專案認真養，而且**已經有機器和備份習慣** → **Vaultwarden**
- 只是要安全地放幾把金鑰憑證，**越少維護越好** → **KeePassXC**
- 不需要附件，只想要能用就好 → **Bitwarden 官方免費版**

最後一個提醒：**不要為了省 $10 而選一個你不會好好備份的方案**。密碼管理器的失敗模式是災難性的，而商業方案付的那筆錢，買的其實是「別人幫你做備份」。
