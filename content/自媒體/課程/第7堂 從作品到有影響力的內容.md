# 第7堂｜從作品到有影響力的內容

**今天的產出**：你自己作品的「**新開場（前 3 秒）**」＋一張「**9:16 封面**」，以及同組同學給你的一句修改建議。

| 區塊               | 時間  | 你要做什麼                       |
| ------------------ | ----- | -------------------------------- |
| 一、觀眾心理與結構 | 50 分 | 聽講，記下 3 個重點              |
| 二、開場鉤子設計   | 40 分 | 為自己的作品寫 3 個開場，選 1 個 |
| 三、小組互評       | 55 分 | 互相看「前 3 秒」，給一句建議    |
| 四、平台差異＋封面 | 35 分 | 用 Canva 做出自己影片的封面      |

> [!tip] 開始前先準備
>
> - [ ] **筆電**開機、插電，能上網
> - [ ] 筆電上有你 **10/4 完成的作品（v1）**，打得開、能播。如果檔案還在手機，現在就傳到筆電（AirDrop、雲端硬碟、傳輸線擇一）

> - [ ] 已登入 Canva（用電腦的瀏覽器，8 月教過，不用重學）

## 一、觀眾心理與結構（50 分）

這段以講解為主。你只需要記下三件事：

- [ ] 觀眾**前 3 秒**就在決定要不要繼續看
- [ ] 一支影片的基本結構：**鉤子 → 鋪陳 → 高潮 → 收尾**
- [ ] 開頭**兌現標題和封面的承諾**，不放冗長片頭、不放 logo

> [!example] 當代案例：MrBeast 的留存原則
> 開頭幾秒不放片頭、直接兌現標題與縮圖的承諾，之後每 20–40 秒再「鉤」觀眾一次（倒數、轉折、不留空氣）。
> 整理文：[TubeBuddy 摘要](https://www.tubebuddy.com/blog/mrbeast-youtube-success-tips/)

### 賞析：看真正吸睛的作品

老師每支只播**前 3–10 秒**就暫停。你只做一件事：**如果我在滑手機，會停下來嗎？為什麼？**

| 作品                                           | 長度      | 連結                                                | 我的第 3 秒感覺 |
| ---------------------------------------------- | --------- | --------------------------------------------------- | --------------- |
| Google〈Parisian Love〉(2010)                  | 約 1 分鐘 | [觀看](https://www.youtube.com/watch?v=UejEaBAYIbc) |                 |
| Metro Trains〈Dumb Ways to Die〉               | 約 3 分鐘 | [觀看](https://www.youtube.com/watch?v=wuP-H1_MzcU) |                 |
| Old Spice〈The Man Your Man Could Smell Like〉 | 約 30 秒  | [觀看](https://www.youtube.com/watch?v=lIYGfeENI0w) |                 |
| Dove〈Real Beauty Sketches〉(2013)             | 約 3 分鐘 | [觀看](https://www.youtube.com/watch?v=rrHoDJinMQI) |                 |
| 全聯〈經濟美學系列〉（2015 年 4A 創意獎）      | 短秒數    | [觀看](https://www.youtube.com/watch?v=MfE_1gerJIE) |                 |

> [!note]- 老師公布後再看：它們用了哪種鉤子？
> 參考答案，以課堂講解為準。
>
> - Parisian Love：只用搜尋框打字說故事（懸念）
> - Dumb Ways to Die：可愛動畫配上蠢死法（反差）
> - Old Spice：直接對鏡頭喊話（直接承諾）
> - Real Beauty Sketches：不看本人、只憑描述畫像（提問／懸念）
> - 全聯經濟美學：留給老師課堂上討論

**完成標準**：不看筆記，你能說出「鉤子—鋪陳—高潮—收尾」四段各自的任務。

## 二、開場鉤子設計（40 分）

### 步驟 1：認識 4 種常用鉤子（5 分）

| 類型       | 做法                         | 例子                                       |
| ---------- | ---------------------------- | ------------------------------------------ |
| 結果先行   | 先給最精彩的畫面，再倒回去說 | 先放最後的成果，再說「這要從三小時前說起」 |
| 提問／懸念 | 丟出一個觀眾想知道答案的問題 | 「為什麼他每次都遲到？」                   |
| 衝突／反差 | 一開始就放矛盾或意外         | 安靜的畫面，突然一聲巨響                   |
| 直接承諾   | 一句話說清楚你會看到什麼     | 「30 秒教你拍出不晃的鏡頭」                |

### 步驟 2：回頭看你的作品（5 分）

- [ ] 在筆電播放你作品的前 3 秒
- [ ] 問自己：**如果我是路人，會停下來嗎？** 寫下「會」或「不會」和原因

### 步驟 3：寫 3 個新開場（20 分）

- [ ] 在筆電新增一份文件（記事本、Google 文件都可以），標題寫「**我的 3 個開場**」，存進「影視創作課」資料夾
- [ ] 至少 **2 個用不同類型**的鉤子
- [ ] 每個開場寫成一句話：「第 1 秒是（　　　），第 3 秒前觀眾會看到（　　　）」
- [ ] 可以使用你**已拍好的素材**，不用重拍

### 步驟 4：選 1 個（10 分）

- [ ] 圈出你最想試的那個
- [ ] 用一句話說明為什麼選它

**完成標準**：文件裡有 3 個開場、其中 1 個被圈起來並寫了理由。

> [!warning] 常見卡關
>
> - **想不出來** → 回去看你自己作品中**最好看的一個畫面**，把它搬到最前面，就是「結果先行」。
> - **想太大** → 不用重拍。今天只是決定「開場排哪個畫面」，剪接是第 8 堂的事。

## 三、小組互評（55 分）

目標只有一個：**互相點出前 3 秒夠不夠抓人**。不評整支片，不評技術。

### 分組

- [ ] 3–4 人一組，確認組員

### 流程（每位作品約 10 分）

| 步驟 | 時間 | 做法                                                             |
| ---- | ---- | ---------------------------------------------------------------- |
| 1    | 1 分 | 作者**不講解、不解釋**，用筆電直接播放作品前 3 秒（可重播 1 次） |
| 2    | 2 分 | 其他人**各自**在回饋卡寫下三項（見下）                           |
| 3    | 5 分 | 輪流說出看法，作者**只聽、只記**，不辯解                         |
| 4    | 2 分 | 作者唸出你選的新開場（步驟二選的那個），大家說哪個比較抓人       |

最後留約 **10 分**，每人把得到的建議整理成一句話，寫進你的文件。

### 回饋卡（給每位同學各寫一張）

1. 看完前 3 秒，**我想繼續看嗎？** 想 ／ 不想
2. **為什麼？**（一句話，說看到的畫面，不說「感覺不錯」這種空話）
3. **一句話修改建議**：「如果把\_\_\_\_放到最前面，會更抓人」

### 你的任務

- [ ] 輪到我時：不解釋，直接播
- [ ] 輪到別人時：每人都寫完回饋卡再發言
- [ ] 結束後：寫下「**我要改的一件事**」

**完成標準**：你手上有組員給你的 2–3 句具體建議，並寫下自己要改的那一件事。

> [!warning] 常見卡關
>
> - **說不出缺點** → 改問「第 3 秒的時候，你在看什麼？有沒有哪一秒開始分心？」
> - **只說好話** → 回饋卡第 3 項不能空白，一定要寫一個「如果……會更好」。

## 四、平台差異＋Canva 封面（35 分）

### 平台差異速查

| 項目       | YouTube Shorts | Instagram Reels | TikTok               |
| ---------- | -------------- | --------------- | -------------------- |
| 直式比例   | 9:16           | 9:16            | 9:16                 |
| 建議解析度 | 1080×1920      | 1080×1920       | 1080×1920            |
| 最長時間   | 3 分鐘         | 3 分鐘          | 站內錄製最長 10 分鐘 |

> [!warning] 規格會改版
> 以上依 **2026-11** 整理的資料，各平台常改規格。要正式發佈前，請到各平台官方說明中心再確認一次。
> 對照表可參考：[Kapwing 規格指南](https://www.kapwing.com/resources/social-media-video-aspect-ratios-and-sizes-the-2025-guide/)

### Canva 封面步驟（Canva 8 月教過，這裡只列檢核）

**1. 開檔（3 分）**

- [ ] 用筆電瀏覽器開 Canva → 新增設計 → 自訂尺寸 → **1080 × 1920 px**

**2. 內容（20 分）**

- [ ] 放一張**你影片裡最有張力的畫面**當背景（在筆電播放你的影片，暫停在最好看的一格，截圖後上傳到 Canva）
- [ ] 標題文字**一眼看得完**，越短越好（建議 8 字以內，這是經驗值，不是規定）
- [ ] 字要**大**、與背景**對比明顯**，縮小到手機縮圖大小仍然看得清楚
- [ ] 標題文字上下各留一些空白，避免被平台介面蓋住

**3. 對照檢查（5 分）**

- [ ] 封面的承諾和你選的**新開場一致**（封面說什麼，前 3 秒就要兌現）
- [ ] 把封面縮小看一眼：**3 秒內看得懂在講什麼嗎？**
- [ ] 把封面傳到手機（或在手機開 Canva），用手機實際看一次縮圖大小

**4. 匯出（5 分）**

- [ ] 下載為 **PNG**
- [ ] 檔名：`組別_作品名_封面`
- [ ] 存進「影視創作課」資料夾，第 8 堂會用到

**完成標準**：資料夾裡有一張 1080×1920 的封面 PNG，且與你的新開場一致。

> [!warning] 常見卡關
>
> - **版面太滿** → 刪到只剩「一個畫面＋一句話」。
> - **字看不清楚** → 加深色底或加粗，不要靠縮小字體硬塞。
