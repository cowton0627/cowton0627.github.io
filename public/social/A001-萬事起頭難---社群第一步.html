選擇平台

理清手中的資源

已有一般帳號

  • 1. Google 帳號
  • 2. Meta 聯盟：Facebook、Instagram、Threads、WhatsApp
  • 3. Line 帳號
  • 4. WeChat 帳號
  • 5. 電話：公司用號碼、室話號碼、個人號碼

已有品牌帳號

  • 1. Facebook 粉絲專頁
  • 2. Instagram 商業帳號
  • 3. Google 商家
  • 4. Line 官方帳號
  • 5. Youtube 頻道
  • 6. Podcast 頻道（Apple Podcast、Spotify、Google Podcast⋯⋯）

列出帳號與社群間的關係

例如：某個 Google 帳號 ⇒ 是用來登入某個 Facebook 帳號 ⇒ FB 帳號下有成立一個粉絲專頁

:::success 前面兩圖表示說，我使用 LINE 帳號登入，在我的 LINE 帳號底下開出兩個 LINE 官方帳號，並且由我登入的 LINE 帳號去管理。

而登入時，使用 LINE 帳號或商用帳號的差異在於，如果你註冊時使用 LINE 帳號註冊，就會用 LINE 帳號登入去管理；如果想要分治，例如不想把自己帳號跟公司的 LINE 官方帳號混在一起，註冊時就使用公司電子郵件註冊會更安全方便。 :::

風險評估

粉絲專頁留下的聯絡方式若是這個 Google 帳號，表示如果這個帳號被盜用，連帶地帳號旗下管理的其他帳號（粉專、頻道⋯⋯）都有可能被盜用。

同理，粉絲專頁留下的電話號碼，若是通訊軟體的登入之用，當它被盜用，旗下管理的其他帳號（Line 官方帳號）也會被盜用。

形式的選項

以露出來判斷

  • 1. 願意露臉
  • 2. 不願意露臉
  • 3. 視情況露臉

:::success 露臉無限制，不願意露臉就是圖、文、圖文、Podcast 可以做，視情況露臉則也適合 IG Reels、Youtube Shorts 等短影音，或者是虛擬形象角色。

p.s. 虛擬形象角色歸類在於視情況露臉的原因是，不願意露臉的人，甚至不想有一個面對鏡頭的形象；而想要創造一個面對鏡頭形象的人，不能說是完全不想露臉的人。 :::

以製作麻煩程度來判斷

  • 1. 有足夠時間
  • 2. 時間絕對不夠
  • 3. 有一點時間

:::success 有足夠時間無限制，時間不夠的人建議先專注在一個平台上面，除非是有夥伴一起經營的人，而有一點時間的人，更需專注在一個平台、容易製作、容易上架，那就建議只由手機操作上架，以此為前提，IG 的圖文最適合。 :::

衡量自己擁有的技能

  • 1. 會編導
  • 2. 會攝影
  • 3. 懂美工
  • 4. 懂剪輯
  • 5. 懂社群操作
  • 6. 喜歡學習新事物的心

:::success 就算沒有前面五點，也要有第六點特質。 :::

手上擁有的貴重器材

  • 1. 手機
  • 2. 筆電
  • 3. 桌電
  • 4. 錄音機
  • 5. 無線麥克風
  • 6. 有線麥克風 (需含麥克風架)

手上擁有的輔助器材

  • 1. 矮腳架
  • 2. 一般腳架
  • 3. 兔籠
  • 4. 穩定器
  • 5. 手燈
  • 6. 立燈
  • 7. 反光板

:::warning 有想要好好經營自媒體的人，建議還是準備一支手機、一台筆電，因為筆電有許多功能或是方便程度，都是手機比不上的，手機只是便利。

另外，雖然有好的軟體，仍需搭配好的硬體才能有好的素材，好的成品。 :::

內容創作者 / 提供者

以 Podcast、RSS Feed 舉例

  1. Podcast 主流平台有許多種，但無法透過單一主流平台直接上架其他主流平台，比方說從 Spotify 上架到 Apple Podcast，所以我們會需要中介平台。
  2. SoundOn 即是這個中介平台的其中之一，透過 SoundOn 產生的 RSS Feed 來餵食給 Spotify、Apple Podcast，就可以在你的內容更新時，主流平台也更新了你的內容，這時主流平台就有點像是 RSS Reader。
  3. 然而，回到 RSS Reader，並不是所有的網路內容都有支援 RSS Feed，所以為特定平台的特定頻道產生 RSS Feed 也是一種服務。

:::success 也就是說，當你在做內容創作者的同時，也可考慮做為內容提供者。

當然，內容提供者絕非易事，但在突破後更容易發現新藍海。 :::

重製影片內容與二創

  1. 舌尖上的印度，這類影片就是使用印度生活的日常紀錄去重製為一個趣味影片，重製影片的為內容創作者，但並沒有一個真正的內容提供者，因為內容提供者應當要有收入來源，例如版權費。
  2. 古早的影片已經不再具有版權，這類的藝術創作已成為公共財，比方說綠野仙蹤 - Part1、綠野仙蹤 - Part2，甚至可以在 Youtube 上找到整部影片。
  3. 以文字來說，安徒生童話這類古早的文字創作也是公共財。

:::info 而二創的合理使用原則可參考著作權如是說。 :::

在著作權法第 44 條至第 65 條有列舉不少符合合理使用原則的情況，例如：學校授課需要、圖書館收藏、媒體報導、家庭內非營利使用等，都可能主張合理使用。 出處

  1. 以影片來說，並不是你買了 OTT 如 Netflix 就可以在學校播放給學生看，在過去，校園播放 VCD、DVD 其實必須要買所謂公播版，就好比 Microsoft 授權 Office 給企業帳號，一個帳號底下有五十個員工使用，當然，這種企業授權方式有優惠，所以私自販售序號也是違法的。

:::info 接著，二創有沒有侵權的判斷可以參考如下： :::

ㄧ. 使用者有沒有商業營利或目的 二. 著作本身的性質是什麼（例如：文字、圖像） 三. 所利用的著作佔整體著作的比例（例如：擷取片段或全部引用） 四. 使用結果對於著作潛在市場、現在價值的影響（例如：影響原作的銷售狀況） 出處

  1. 以有版權的創作來說，不得是二創全片的 100%，而引用片段必須在於原片的 1/10 以內，這參照的案例為誠實預告與谷阿莫。
  2. 如果想要引用別人的創作，最好還是告知創作者，周星馳的《功夫》其實與金庸的《神鵰俠侶》並無關係，但因為裡面用到楊過、小龍女的稱呼，他還是跑去找了查先生的後人請求授權。

:::info 再者，C.C. 音樂的引用也可以參考，這些創作者也希望自己的音樂被推廣，所以只要求影片片尾註明出處即可使用，這即是在合理的使用範圍。

所以以推廣、分享為出發點，是身為一個內容創作者的最佳實作。 :::

  1. 如果你是說書人頻道，那你就是內容創作者，用你的話來解讀一本書的精華；如果你是寫書的人，授權給說書人頻道，那你就是內容提供者。也許可以朝內容提供者是 C.C. 的方向去找尋，免費、限時免費、無版權、可商用都有自己的獨特意義存在。

:::success 活在生成式 AI 的爆發年代，內容創作者也可以很幸福地創作內容，這包括對話機器人、生圖機器人、音樂機器人、簡報機器人⋯⋯等，因為都是可商用的。

所以以說書人為目標來說，創作者可以更容易創作自己的說書人頻道。 :::
